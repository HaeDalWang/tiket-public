# AWS 조직(Payer)을 옮기면 Bedrock 의 Claude 4.7 이상 모델이 막히는데, 미리 묻지 않거나 복구를 약속하기 쉽다

## 무엇을 하면 틀리는가

- 조직 이동·신규 링크를 일반 작업처럼 안내하고 **Bedrock·Claude 사용 여부를 묻지 않는다.** 이동 뒤 고객 서비스가 멈춘다.
- "이동할 Payer 계정에서 케이스를 열어 미리 풀어 두겠다" 고 답한다. 그 방법은 되지 않는다.
- 차단된 뒤 "케이스를 열면 복구된다", "며칠이면 된다" 고 **기간이나 복구를 약속한다.**
- AWS 에서 "복구됐다" 는 회신을 받고 **모델을 실제로 불러 보지 않은 채** 고객에게 해결됐다고 알린다.

## 실제로 있었던 일

- 2026-10-02: msp-team 채널에 대응 방법이 공지됐다(게시일은 확인하지 못했다 — 유지보수자가 전달한 날이다).
  조직 이동 뒤 Claude 모델 접근이 막힌 사례들이 있었고, 복구 회신을 받고도 모델을 쓸 수 없어 2~3일이 더 걸린 사례가 있었다.

## 확인된 사실

아래는 사내 공유다 — 증언이지 AWS 가 문서로 밝힌 사실이 아니다. 조직 이동이 차단을 일으킨다고 설명한 AWS 공식 문서는
찾지 못했다(2026-10-02 AWS 문서 검색).

- 조직 이동 시 Bedrock 의 Claude 모델 접근이 차단된다. 확인된 범위는 **4.7 버전(Opus·Sonnet)부터 최신 모델까지**다.
- 이동할 Payer 계정에서 케이스를 열어 차단을 미리 막는 조치는 **불가하다.** 별도 협의가 필요하다.
- 사전 조치가 가능한지 묻는 창구는 AWS Support Plan 에 따라 다르다 — Basic 고객사는 MSP 회사 영업과 AWS AM, PLS 대상 계정은 TAM.
- 차단된 뒤에는 **실제로 차단된 고객 계정에서** Support Case 를 열어 복구를 요청한다.
- 케이스에 모델명·리전, 차단된 모델을 쓰고 있었는지, 구체적인 업무 목적과 활용 방식, 홈페이지 URL(있으면)을 같이 적는다.
  적지 않아도 뒤에 요청받을 가능성이 높다.
- Basic 은 케이스 배정부터 복구 회신까지 약 1~2주가 걸릴 수 있다. 배정이 오래 걸리므로 Chat 으로 여는 편이 낫다.
- 복구 회신을 받고도 모델을 쓸 수 없었던 사례가 있다 — 2~3일이 더 걸렸다.
- **위 조치는 복구를 보장하지 않는다.** 복구 여부는 케이스마다 다르다.

공식 문서로 확인한 것은 주변 사실뿐이다 — `AccessDeniedException … model is not available for this account` 는 모델 접근 설정이 아니라
계정 수준 제한일 수 있고, Anthropic 모델은 처음 쓰기 전에 사용 사례 양식(FTU)을 내야 한다
(https://repost.aws/knowledge-center/bedrock-invokemodel-api-error).

## 해야 할 것

**조직 이동·신규 링크 문의를 받으면 (이동 전)**

1. 그 계정이 Bedrock 에서 Claude 를 쓰는지, 어느 모델·리전인지, 멈추면 어떤 업무가 영향받는지 고객에게 묻는다.
2. 쓰고 있으면 이동 뒤 4.7 이상 모델이 막힐 수 있다고 **이동 전에** 알린다. 일정을 정하기 전에 알린다.
3. 사전 조치가 가능한지는 사람이 확인한다 — Basic 은 MSP 회사 영업과 AWS AM, PLS 대상 계정은 TAM. 에이전트는 문의 초안만 쓴다.
4. "Payer 에서 미리 풀어 두겠다" 고 쓰지 않는다.

**이동 뒤 막혔다는 문의를 받으면**

1. 차단된 고객 계정에서 Support Case 를 열도록 안내한다(사람이 연다). Basic 이면 Chat 을 권한다.
2. 케이스 초안에 모델명·리전, 차단된 모델 사용 여부, 업무 목적과 활용 방식, 홈페이지 URL 을 넣는다. 모르는 값은 고객에게 묻는다.
3. 회신에는 Basic 기준 약 1~2주가 걸릴 수 있고 복구가 보장되지 않는다고 적는다. 날짜를 약속하지 않는다.
4. AWS 가 복구됐다고 회신하면 **고객이 모델을 실제로 호출해 본 결과**를 받은 뒤에 해결로 적는다.

## 다시 쓰기 전에 확인할 것

- **차단 범위.** "4.7 부터 최신까지" 는 2026-10-02 공지 시점의 범위다. 새 모델이 나오면 달라진다 — msp-team 채널의 후속 공지를 본다.
- **그 계정의 AWS Support Plan** — 문의 창구와 예상 기간이 여기서 갈린다.
- 고객이 받은 오류 문구와 리전. 조직 이동과 무관한 접근 거부(IAM·SCP·FTU 미제출)와 구분한다.
- 사전 조치 협의 결과가 바뀌었는지 — 영업·AM·TAM 에게 사람이 확인한다.
