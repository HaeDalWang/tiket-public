# 근거. 줄마다: 조회일 | 종류 | 위치 | 버전
#   종류   aws-doc · aws-repost · vendor-doc          위치는 https:// URL
#          aws-api · aws-managed-policy · aws-support  API 이름, 정책 이름, 케이스 번호
#          billing-api · billing-portal              endpoint, 포털 메뉴 경로
#          account-observation · poc                   무엇을 어떻게 조회·재현했나 (계정 ID 금지)
#          internal-share                              사내 공유. 증언이지 사실이 아니다
#          ticket                                      이미 일어난 사건의 기록. 이것만 낡지 않는다
#   버전   문서 "마지막 업데이트", API 버전, 관리형 정책 버전, 포털 화면 시점 등.
#          없으면 `표기 없음`, 해당이 없으면 `해당 없음` 이라고 적는다. -·?·모름 은 막힌다
#          — 비워 두면 "안 봤다"와 "없다"가 구분되지 않는다
#   본문에 인용하는 URL 은 전부 여기에 있어야 한다
