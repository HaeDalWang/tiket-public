# 계획서 · 현장 교훈 승인 — 리드가 "처리 지침" 을 직접 적는다

- **상태**: 계획 (2026-09-29). MSP 사이트 저장소(`~/work/MSP_주간회고`)에 넘길 기능 명세다.
  같은 날 AI 초안 생성안을 썼다가 버렸다 — 초기 단계에 인프라·토큰 비용이 과하다(유지보수자 결정).
- 배경: 첫 실제 후보(`policy`)가 들어왔고, 팀 리드가 "승인하면 어떤 규칙이 생길지 몰라 누르기 어렵다" 고 했다.
  지금 화면은 승인·반려·병합 버튼과 "결정 사유" 칸뿐이라 리드가 할 수 있는 말이 예/아니오다.
  그런데 "정해진 규칙이 없다" 는 교훈에 필요한 것은 예/아니오가 아니라 **리드의 지침**이다.
- 앞선 계획 [[2026-09-28-candidate-review-site]] 를 고친다. 사이트 작업자는 사이트 `AGENTS.md` 를 먼저 따른다.

## 1. 한 줄 목표

리드가 후보를 보고 **"이런 경우는 이렇게 처리하라"** 를 짧게 적는다. 그 글을 유지보수자가 나중에 규칙 카드로 만든다.
사이트는 받아 적기만 한다 — AI 초안·새 테이블·새 인프라 없음.

## 2. 바꿀 것

**화면 문구와 입력칸만 바꾼다. 저장 위치는 지금의 `review_note` 그대로다.**

| 지금 | 바꾼 뒤 |
|---|---|
| 결정 사유 칸 (승인은 선택) | 승인할 때: **"처리 지침"** 칸. 반려·병합할 때: 지금처럼 "사유" |
| [승인] | [이 지침으로 승인] — `policy`·`playbook` 은 지침이 비면 눌리지 않는다 |
| 승인 확인창 | "승인하면 근거 원문이 지워지고 되돌릴 수 없습니다. 적은 지침이 규칙의 근거로 남습니다." |

지침 칸 안내 문구(placeholder) — 고정 양식, 종류별:

- `policy` 회사 규칙: "어떤 경우에 · 누가 · 어떻게 처리하고 · 고객에게 어디까지 말하는지 적어 주세요.
  예) 무단 사용 요금 조정 요청은 MSP 담당자가 Payer 에서 케이스를 연다. 고객에게는 접수 사실만 알리고 조정 여부·금액은 약속하지 않는다."
- `playbook` 업무 방법: "이 일을 할 때의 순서나 꼭 확인할 것을 적어 주세요."
- `pitfall`·`customer`: 지금처럼 선택. 안내 문구 "덧붙일 말이 있으면 적어 주세요."

(예시 문장은 형식 안내일 뿐이다. 실제 방침이 아니다.)

## 3. 규칙

- 서버도 막는다: `policy`·`playbook` 승인에 `note` 가 비면(공백 제외) 400 "처리 지침을 적어 주세요."
  나머지 결정 규칙(한 번만 · 반려·병합 사유 필수 · 승인 시 근거 삭제 · 4000자)은 그대로.
- 이 규칙은 수집기 CLI `decide()` 와 어긋난다(CLI 는 승인 사유가 선택). CLI 는 유지보수자만 쓰므로
  **사이트만 먼저 바꾸고, CLI 는 백로그에 둔다.** [[2026-09-28-candidate-review-site]] 4절의 "CLI 가 정본" 원칙에서
  벗어나는 것을 여기 적어 둔다.

## 4. 승인 뒤

- "승인됨" 목록의 "git 파일로 옮길 것"에 처리 지침 · 결정자 · 날짜를 보인다(지금 `review_note` 표시를 지침 이름으로).
- 유지보수자가 지침을 카드로 옮긴다. 출처는 "사이트 현장 교훈 결정 `<candidate_id>`, <날짜>, <결정자 역할>".
  **지침을 넘어서는 내용은 카드에 넣지 않는다.** 필요하면 리드에게 다시 묻는다.

## 5. 테스트

| 층 | 무엇을 |
|---|---|
| 결정 API | `policy`·`playbook` 승인에 빈 지침 400 · 공백만 400 · `pitfall` 은 지침 없이 승인 · 기존 규칙 테스트 그대로 통과 |
| E2E | `policy` 후보 상세 → 지침 비면 [이 지침으로 승인] 비활성 → 입력 → 승인 → 승인됨 목록에 지침 표시 |

변이 확인: 서버의 지침 필수 검사를 끄면 API 테스트가 깨져야 한다.

## 6. 완료 기준

첫 실제 후보를 팀 리드가 지침을 적어 승인 → 유지보수자가 tiket 카드로 옮겨 릴리스 → 지식 도서관에 뜬다.

## 7. 하지 않는 것

AI 초안, 별도 테이블, 질문 목록, 초안 편집기, git 카드 자동 생성. 후보가 쌓여 유지보수자가 병목이 되면 그때 다시 본다.
