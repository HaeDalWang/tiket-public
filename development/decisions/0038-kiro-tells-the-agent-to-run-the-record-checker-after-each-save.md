# 0038. Kiro 는 기록을 저장할 때마다 에이전트에게 검사기를 돌리라고 말한다

- **언제**: 2026-10-06
- **정한 것** (유지보수자 — "훅 같은 걸 만들어서 최종 티켓 작성 시 꼭 지켜야 할 걸 확인하도록", 과한지 물은 뒤 확인을 거쳐 진행):
  - `.kiro/hooks/ticket-record-check.json` 을 둔다. `PostFileSave`, `tickets/<이름>.md` 에만, 지시문 훅(`type: agent`).
    `scripts/render_agent_configs.py` 가 만든다.
  - 훅은 **새 규칙을 들지 않는다.** `check_ticket_record.py` 를 돌리라고만 한다 — FAIL 이면 고치고 다시, PASS 면 아무것도 안 한다.
  - **막지 않는다.** 저장은 이미 끝난 뒤다. 알리기만 한다.
  - 대기 칸에 있던 `Stop` 훅("산출물 없이 끝나면 경고")을 이것으로 대신한다. 꺼낼 조건이던 훅 없는 기준선은 2026-10-04 에 나왔다.
- **왜**: 동료 기록은 16건 중 9건이 검사 FAIL 이다(2026-10-04 조회). "검사기를 돌려라" 는 이미 문서에 있다 — 문구를 더 조이지 않고 장치로 간다.
- **실측** (kiro-cli 2.27.1, v3. 평가 사본에 탐침 훅을 걸었다):
  - `PostFileCreate`·`PostFileSave`·`PostToolUse`·`Stop` 넷 다 돈다. `PostFileSave` 는 새 파일에도 돈다. 입력의 `file_path` 는 절대 경로다.
  - **명령 훅의 출력은 에이전트에게 안 간다** — 종료 0 의 stdout 도, 종료 1·2 의 stderr 도, `Stop` 의 종료 2 도. 문서(kiro.dev/docs/hooks/actions)는 간다고 적는다.
    그래서 "훅이 검사기를 돌려 결과를 보여 준다" 가 아니라 "에이전트에게 돌리라고 시킨다" 다.
  - 지시문 훅의 `action.type` 은 `agent` 다. `prompt`·`askAgent`·`agentPrompt` 는 돌지 않는다.
  - 비용: `EVAL-003` 훅 3회 104·106·121초, 훅 없이 3회 114·116·119초. 회차마다 한 번 발동, 되풀이 없음.
  - TUI(Orca 터미널, 내장 에이전트): 기록을 FAIL 나게 고치게 했더니 지시문을 받고 검사기를 돌려 되돌린 뒤 PASS 를 확인했다.
  - 생성기가 만든 파일 그대로 한 회차: 저장 → 훅 → 검사 FAIL(출처 없는 `[확인]`) → 고침 → 훅 → 검사 통과.
- **모르는 것 · 한계**:
  - **효과는 평가로 못 쟀다.** 훅 없는 Kiro 도 평가에서는 검사기를 스스로 돌린다(기준선 12회 전부). 동료 FAIL 이 검사기를 안 돌려서인지
    쓰다 만 기록이라서인지 모른다. 릴리스 전후 사용 지표의 주별 검사 결과로 본다.
  - 사용자가 일부러 FAIL 상태로 두라고 해도 훅 지시가 이긴다(되돌리고 이유를 보고했다).
  - 훅이 발동했다는 표시가 TUI 화면에 없다.
  - 긴 세션에서 저장마다 한 바퀴 더 돈다 — 크레딧. 평가에서는 저장이 한두 번이라 안 보였다.
  - Kiro IDE·Windows 는 안 봤다. Claude Code·Codex 에는 넣지 않았다 — 같은 장치가 되는지 따로 확인한다.
  - **평가 조건이 바뀐다**: 이 커밋 뒤의 평가 사본에는 훅이 들어 있다. 2026-10-04 기준선과 나란히 놓을 때 적는다.
