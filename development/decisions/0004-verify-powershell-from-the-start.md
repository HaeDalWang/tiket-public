# 0004. PowerShell 을 처음부터 같이 만든다

- **언제**: 2026-09-04
- **정한 것**: 사용자 대면 스크립트는 `.sh` 와 `.ps1` 을 **동시에** 만들고, 둘이 어긋나는지
  `scripts/test_onboarding_parity.py` 가 검사한다.
- **왜**: "나중에 Windows 지원 추가"는 실제로는 영영 안 온다. 그리고 어긋남은 조용하다 —
  `support-skills` 는 `install.ps1` 이 `install.sh` 의 파일 목록 두 개를 빠뜨린 채
  배포돼 Windows 설치가 통째로 깨졌고, 두 목록을 비교하는 테스트가 없어서 CI 를 그냥
  통과했다. 그 사고를 그대로 베껴 막는다.
- **테스트가 고정하는 것**: 단계 이름과 순서, 설정 파일 경로, conf 키, 토큰 입력 은닉
  (`read -rs` / `-AsSecureString`), 비대화형 확인 모드, 셸 프로필 미접촉, 인라인 이미지
  탐지, 자격증명을 우리 호스트에만 전송.
- **버린 선택지**:
  - **`.sh` 먼저, `.ps1` 은 나중에** — 위 이유로 기각.
  - **문서로만 "둘 다 고치세요"** — 지키는지 아무도 확인하지 않는다.
- **아직 못 한 것**: `pwsh` 실행 검증. 이 머신에 PowerShell 이 없고 Homebrew 캐스크가
  sudo 를 요구한다. **구조 일치만 테스트로 보장되고 실제 실행은 미검증 상태다.**
  설치되면 `-Check` 모드부터 돌려야 한다.
