# 0001. 무거운 티켓 형식을 버리고 한 파일로

- **언제**: 2026-09-04
- **정한 것**: 티켓 하나 = 파일 하나(`tickets/<번호>.md`), 5섹션. Decision Packet v2 / Reply
  Brief v2 JSON, `current`/`evidence`/`history` 3파일 분할, 프로필 선행 강제를 전부 뺐다.
  근거 등급 `[확인] [추측] [모름]` 만 남겼다.
- **왜**: 티켓 하나 답하기 전에 규칙·템플릿 **35,234자**를 먼저 읽어야 했다. 티켓 본문도,
  AWS 조회도, 공식 문서도 아직 안 읽은 상태에서. Decision Packet v2 + Reply Brief v2
  만으로 3,481자다. 실사용자 평가가 "토큰 많이 먹고 느리고 쓸데없이 많이 기록해서
  방해만 된다 — 사람이 조언하는 게 빠르다" 였다. 쓰이지 않는 안전장치는 안전장치가 아니다.
- **버린 선택지**:
  - **스키마를 유지하고 문서만 줄이기** — 무게의 근원이 스키마 자체다. 채우는 데 드는
    시간이 답을 쓰는 시간을 넘었다.
  - **전부 삭제** — validator·템플릿·examples 가 얽혀 있어 되돌리기 어렵다. 규칙만 먼저
    바꿨고 파일은 남겨뒀다. 규칙 수정은 몇 줄이라 되돌리기 쉽다.
- **남긴 이유**: `[확인]/[추측]/[모름]` 은 자신 있게 틀리는 걸 막는 유일한 장치이고
  비용이 단어 세 개뿐이다.
