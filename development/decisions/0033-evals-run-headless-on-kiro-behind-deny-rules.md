# 0033. 평가는 Kiro 를 사람 없이 돌리고, 안전은 사본 전용 deny 규칙이 지킨다

- **언제**: 2026-10-02
- **정한 것**:
  - `scripts/eval_run.py` 가 케이스를 Kiro CLI 로 돌린다 — 사용자 대부분이 Kiro 라서 Kiro 가 먼저다(유지보수자).
    회차마다 `git archive` 로 만든 사본에서 돌리고, 사본에서 `evals/`·`development/` 를 지운다. 결과는 저장소 밖 `~/work/tiket-eval-runs/` 에 둔다.
  - `--trust-all-tools` 를 쓰지 않는다. 사본 폴더 전용 `permissions.yaml` 을 넣고 끝나면 지운다. 허용은 프레임워크 스크립트 셋,
    사본 안 읽기 명령, `tickets/` 쓰기, 문서 조회(MCP `aws-docs`·`exa`, 웹)뿐이고 **그 밖의 셸 명령과 MCP 서버는 `deny` 로 못 박는다.**
  - 채점은 하지 않는다. 형태 검사(`check_ticket_record.py`)까지 돌리고, 경계·근거는 기록을 읽고 채점한다(2026-09-24 결정 그대로).
- **왜**: 손으로 돌리면 답안지·이전 기록·옆의 고객 파일이 답을 도왔고(0031), 케이스 5건 × 3회만 해도 손으로는 못 돌린다.
  그런데 승인 없이 돌리면 2026-10-02 2회차처럼 브로커에 로그인해 실제 고객을 조회할 수 있다. 자격증명은 홈 폴더에 있어 사본으로는 안 끊긴다.
- **실측** (kiro-cli 2.27.0 · KAS 0.66.22, macOS):
  - 비대화형에서 규칙에 없는 호출은 거절된다. 공식 문서도 같다 — "When no interactive client is available, every `ask` is treated as a deny".
  - 유지보수자 PC 의 전역 규칙이 `python3 *` 를 허용하고 있어, 허용 목록만 둔 사본에서 `python3 -c "print(1)"` 이 돌았다.
    "deny > ask > allow … regardless of which scope" 이므로 허용 목록 밖을 deny 로 덮었고, 그 뒤에는 거절됐다.
  - `;`·`|`·`&&` 로 이은 명령은 조각마다 본다. 절대 경로·홈·상위 폴더·변수·따옴표 속 절대 경로는 거절됐다.
  - 거절을 "사용자가 거절했다" 로 읽고 멈춘다 — 읽기 명령까지 막은 첫 실행은 64초 만에 기록 없이 끝났다. 그래서 사본 안 읽기는 연다.
  - 규칙을 고친 뒤 `EVAL-002` 한 회차: 140초, 거절 0건, 기록 생성, 형태 검사 PASS. 사본과 권한 폴더는 지워졌다.
- **버린 선택지**:
  - `--trust-all-tools` + 조심 — 평소 사용과 가장 가깝지만 실제 고객 조회를 막을 장치가 없다
  - `HOME` 을 바꿔 자격증명을 가린다 — Kiro 로그인도 같이 사라진다
  - macOS `sandbox-exec` 로 파일 접근을 막는다 — 근본 해법이지만 Kiro 가 읽어야 하는 경로를 다 찾아야 하고 macOS 전용이다. 아래 한계가 실제로 문제가 되면 간다
  - 케이스부터 늘린다 — 막힌 곳은 케이스 수가 아니라 회차 수였다
- **남는 한계**:
  - **입력 리다이렉트는 규칙이 못 본다.** `head -5 < 사본밖파일` 은 통과한다. 맨 `cat` 은 허용하지 않아 `cat<파일` 은 막힌다.
    그런 호출이 돌면 summary.json 의 `escaped` 에 남고 실행기가 경고한다. 경로를 이미 아는 파일만 읽을 수 있고, 읽어도 쓸 명령이 없다.
  - glob 으로 "사본 안인가" 를 정확히 가리지 못한다. 목록에 없는 표기로 밖을 가리키면 샌다.
  - 내 PC 의 Kiro 전역 스티어링과 스킬 목록이 그대로 들어간다 — 동료 환경과 다르다. 무엇이 들어갔는지는 summary 의 `context_files`.
  - 평소 사용과 다르다: 사람이 승인했을 명령(절대 경로를 쓴 읽기 등)이 거절된다. 거절이 많은 회차는 따로 본다.
  - `fetch-ticket.sh` 가 합성 번호로 Zendesk 를 한 번 조회한다. Kiro 버전이 바뀌면 위 실측을 다시 한다.
  - Claude Code·Codex 는 아직 없다.
- **근거**: `scripts/eval_run.py`, `scripts/test_eval_run.py`(머리말에 실측), kiro.dev/docs/permissions(2026-10-02 조회)
