# 0027. 사례는 날짜·출처·버전을 박고 시작한다 — 임시 7건은 지운다

- **언제**: 2026-09-30
- **정한 것**: `pitfalls/*.md` 는 `templates/pitfall.md` 양식을 따르고 `validate_workspace.py` 가 강제한다.
  - `observed` — `날짜 | ticket <번호>` 또는 `날짜 | share <채널>`. 한 줄 이상. 고객은 적지 않는다
  - `sources` — `조회일 | 종류 | 위치 | 버전`. 종류는 닫힌 목록. 웹 문서 종류는 `https://` 필수.
    버전은 비우거나 `-`·`?`·`모름` 으로 피할 수 없다 — 없으면 `표기 없음`, 해당 없으면 `해당 없음`
  - `review_by` — `ticket` 외 출처가 있으면 필수. 지나면 막히고, **가장 오래된 출처 조회일 + 180일**을 넘지 못한다
  - 모든 날짜는 달력에 있는 `YYYY-MM-DD` 이고 오늘 이후가 아니다
  - 본문 `# ` 제목 줄, 6개 섹션이 비어 있지 않을 것, 변경 이력에 날짜 줄, **본문에 인용한 URL 은 전부 `sources` 에**
  - 기존 7건은 임시였으므로 지운다
- **왜**: 7건을 읽어 보니 관측일·참고 문서·조회일·버전이 제각각이었다. 2건(Aurora 스냅샷, 빌링 플랫폼 계정별 비용)은
  출처도 날짜도 없어 판례가 아니라 `[추측]` 이었다. 사례가 지금도 맞는지 판단하려면 "언제 당했나"와
  "그때 무엇의 어느 버전을 봤나"가 필요하다. 정책 카드는 이미 `source_version`·`review_by` 로 강제하고 있었다.
- **첫 양식의 허점 (같은 날 검토)**: 첫 검사기를 속이는 카드 9개를 만들어 돌렸더니 9개 모두 통과했다 —
  `review_by: 2999-01-01`, 출처는 1년 전인데 `verified_at` 만 오늘, 사내 공유만 근거로 기한 없음,
  본문 URL 이 `sources` 에 없음, 미래 조회일, `2026-13-45`, 버전 `-`, `aws-doc` 위치가 URL 아님, 빈 섹션.
  위 규칙은 각각 이것을 막는다. `scripts/test_validate_workspace.py` `test_pitfall_*` 가 하나씩 고정한다.
- **버린 선택지**:
  - `v1.2` 같은 카드 버전 번호 — 손으로 올려야 해서 어긋난다. 필요한 건 **근거의** 버전과 조회일이다
  - `verified_at` — 출처 조회일과 같은 정보의 반복이고, 출처를 다시 열지 않고 날짜만 올리는 길이 된다.
    카드가 얼마나 낡았는지는 가장 오래된 출처 조회일로 계산한다
  - 관측 줄의 고객 칸 — `CUST-NNN` 은 사람마다 번호가 달라(`templates/customer-index.md`) 공용 카드에서
    다른 고객을 가리킨다. `corpId` 도 아니다 — 사례는 패턴이고, 고객 사정은 git 이 아니라 후보 테이블에 둔다(0026).
    티켓 번호가 원 건으로 가는 길이고, 그 기록에 `corp_id` 가 있다
  - 출처 **출처지**(사내/외부)로 만료 면제 — 사내 공유도 AWS 에 대한 주장이면 낡는다(지운 루트 이메일 사례).
    면제는 이미 일어난 사건의 기록인 `ticket` 만
  - frontmatter `title` — 지식 도서관은 첫 `# ` 줄을 제목으로 읽는다. 두 곳에 두면 어긋난다
  - 상한 90일 — 정책 카드 운영값이지만, 사례는 재확인 부담 대비 180일로 정했다(유지보수자, 2026-09-30)
  - `playbooks/` 에도 같은 만료일 — 우리 내부 절차라 저절로 낡는 바깥 사실이 없다
- **남는 한계**: 검사기는 형식만 본다. 내용이 참인지는 0026 의 승인이 관문이다.
  만료된 카드는 동료의 온보딩 검증(`scripts/onboarding.sh`)과 릴리스(`scripts/release.py`)를 실패시킨다 — 정책 카드와 같다.
- **근거**: `templates/pitfall.md`, `scripts/validate_workspace.py` `validate_pitfall_*`,
  `scripts/test_validate_workspace.py` `test_pitfall_*`. 지운 7건은 이 결정 직전 커밋에 남아 있다.
