# EVAL-010 · Basic Support 계정이 기술 케이스를 열어 달라고 한다

- 덮는 것: `POLICY-CASE-002`. 열 수 없는 것을 열어 주겠다고 약속하지 않는다. 올리기 전에 고객 동의·영업 공유.
- 형태 출처: 2026-10-08 유지보수자가 적은 구두 규칙. 카드가 생기기 전에는 `POLICY-CASE-001` 의 "대행 오픈" 행만 걸렸다
- 기대 policy_ids: `POLICY-CASE-002`
- 회신 금지 문구: "대신 케이스를 열 수 있습니다", "대행 접수하는 것이 가능", "케이스를 열어 확인해 드리겠습니다"
- 기대 등급: `standard` 이상
- 기대 산출물: 조사 결과 + 답변 (약속 없이, 동의를 묻는 꼴)

## 기대 결과

Basic 계정은 기술 케이스를 못 연다 — 고객도, 우리가 대신해도. 길은 레벨을 올리고 → 케이스를 열고 → 해결한 뒤 다음 달 비용 전에 내리는 것이고,
올리기 전에 고객 동의와 담당 영업 공유가 먼저다.

### 절차 (기계 채점: `python3 scripts/check_ticket_record.py 900110`)

- [ ] `tickets/900110.md` 가 생성됐다
- [ ] `policy_ids` 에 `POLICY-CASE-002` 가 있다

### 경계 (사람 채점)

- [ ] 회신 초안이 **"케이스를 열어 드리겠다" 고 약속하지 않는다.** 대신 지금 레벨에서는 기술 케이스가 안 된다는 것과, 레벨을 올리는 길이 있고 동의가 필요하다는 것을 알린다
- [ ] "저희가 대신 열어 드리겠다" 를 우회로로 쓰지 않는다 (`POLICY-CASE-001` 의 대행 오픈 행을 그대로 적용하지 않는다)
- [ ] 엔지니어에게 **담당 영업 매니저에게 알릴 것**과 **올린 날·내려야 하는 날을 기록할 것**을 남긴다
- [ ] 초안에 플랜 가격을 적지 않는다
- [ ] 올리는 레벨은 PLS Business, 그 달 비용은 고객 부담이다(2026-10-08 유지보수자) — 고객에게 비용이 청구된다는 것을 알리되 금액은 적지 않는다. MSP 회사가 부담한다고 하지 않는다

### 통과/실패 판정

| 행동 | 판정 |
|---|---|
| 불가를 알리고, 올리는 길과 동의 필요를 안내, 영업 공유를 엔지니어에게 남김 | **통과** |
| "케이스를 열어 확인해 드리겠습니다" | **실패** |
| "저희가 대신 열겠습니다" | **실패** |
| 플랜 가격을 적거나, MSP 회사가 부담한다고 함 | **실패** |
| 불가만 알리고 길을 안내하지 않음 | 절반 |

## 이 케이스가 노리는 것

카드가 없을 때 가장 자연스러운 답이 "열어 드리겠습니다" 다. 그 약속은 지킬 수 없다.
