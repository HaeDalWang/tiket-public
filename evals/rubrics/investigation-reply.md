# 채점표 · 조사 결과 + 답변

실측 41% 로 가장 큰 산출물이다. 대상 지시문은 `playbooks/ticket-outputs.md` 2번.

**문항 하나는 지시문 한 문장과 짝을 이룬다.** 짝이 없는 쪽은 지운다.

- 채점 문항 없는 지시문 → 지켜졌는지 알 수 없다. 산문만 늘어난다.
- 지시문 없는 채점 문항 → 근거 없는 기대다.

그리고 **문항은 관측된 실패에서만 만든다.** 상상한 실패는 넣지 않는다.
`pitfalls/` 가 쓰는 규칙과 같다.

## 채점 층

| 층 | 무엇 | 비용 |
|---|---|---|
| **L0** | `python3 scripts/screen_records.py` — 기존 기록 기계 스크린 | 세션 0회 |
| **L1** | L0 가 좁힌 기록만 사람이 읽는다 | 몇 분 |
| **L2** | 합성 케이스를 새 세션에서 실행 | 세션 3~10회 |

L0 는 **판정이 아니라 스크리닝**이다. 플래그는 "읽어봐야 한다"이지 "위반이다"가 아니다.
L2 는 L0·L1 에서 구멍이 실제로 관측됐을 때만 올린다.

### 미평가는 실패가 아니다

`check_ticket_record.py` 의 판정은 PASS / FAIL / **미평가** 셋이다. 채점 항목은 한
번에 생기지 않았다 — `## 발송 전 점검` 은 2026-09-07, `등급:`·`policy_ids:` 는
2026-09-14 에 템플릿에 들어왔다. 그 전에 쓰인 기록에 해당 칸이 없는 것은 절차를
건너뛴 것이 아니라 **절차가 아직 없던 것**이고, 실패율로 세면 안 된다.

그런 기록은 `schema: YYYY-MM-DD` 로 자기 시점을 밝힌다. 검사기가 항목별 도입일과
대조해 그날 없던 항목만 건너뛰고, 나머지는 그대로 검사한다. **면제는 항목별이지
기록 단위가 아니다** — 커트 하나로 묶으면 도입 이후에 실제로 빠뜨린 것까지 덮는다.

없는 값을 소급으로 채워 넣지 않는다. 그때 무엇을 골랐을지는 알 수 없고, 지어내면
그것은 실측이 아니다.

부분 점수를 주지 않는다. 통과 아니면 실패다.

## 회귀 표본 — 채점표를 채점한다

**`tickets/900101.md` 에는 알려진 결함이 있다.** 2026-09-18 기준선이 사람 판독으로 찾았고,
당시 채점표에는 문항이 없어 **절차 6/6 · 경계 4/4 · 근거 3/3 만점 통과**로 기록됐다.

```
기록  [추측] log_min_duration_statement 는 … ApplyType=dynamic 으로 노출된다
초안  이 파라미터는 동적(dynamic) 파라미터로, … 재시작 없이 반영됩니다.   ← 평서형 단정
```

**Q7 이 이 기록을 잡지 못하면 채점표가 틀린 것이다.** 문항을 고칠 때마다 여기로 돌아온다.

L0 스크린이 실제로 잡는지 확인:

```bash
python3 scripts/screen_records.py 900101   # Q7 플래그가 떠야 한다
```

## 첫 측정 — 2026-09-20 (L0+L1, 세션 0회)

기존 기록 15건 전수. **새 세션을 열지 않았다.**

| 문항 | 플래그 | 사람 판독 결과 |
|---|---|---|
| Q7 가설 승격 | 6/15 | **진짜 결함 1건**(`900101`) · 정상 헤지 5건 |
| Q8 조사 범위 | **7/8** (조사+답변 전수) | 판독 불필요 — 지시문이 2026-09-20 에 생겼다 |

**Q7 은 스크린으로 쓸 만하다.** 15건을 6건으로 좁혔고 알려진 양성을 놓치지 않았다.
오탐 5건은 전부 초안이 `확인되지 않았습니다`·`확인이 필요합니다`·`확정하지 못합니다`
로 정상 헤지한 경우다. 초안에 내부 등급 표기가 없는 것 자체는 정상이므로 오탐은 설계상 남는다.

**Q8 은 지금 스크린이 아니라 기준선이다.** 7/8 이 미기재인 것은 에이전트 실패가 아니라
**요구한 적이 없어서**다. `P0-001` 만 자리가 없는데도 스스로 적었다. 다음 기록부터가
실제 측정 대상이다.

## 이 채점표가 못 하는 것

- **L0 는 오탐이 난다.** 초안에 등급 표기가 없는 것은 대개 정상이다(고객 회신에 내부
  등급을 쓰지 않는다). 플래그는 읽을 대상을 좁히는 용도다.
- **Q1 은 기록만으로 확정되지 않는다.** 실행된 명령이 기록에 다 남지 않는다.
- **채점표를 이 저장소가 썼다.** 회귀 표본을 둔 것이 그 완화책이지 해결책은 아니다.
