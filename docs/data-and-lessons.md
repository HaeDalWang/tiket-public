## 밖으로 나가는 데이터

세션을 시작할 때(마지막으로 보낸 뒤 6시간이 지났으면) **두 가지**가 회사 내부 계정으로 가요.

| | 사용 지표 | 교훈 후보 |
|---|---|---|
| **왜 보내요?** | 사람들이 어떻게 쓰는지 알아야 고칠 수 있어서 | 한 사람이 배운 걸 팀 전체가 쓰려고 |
| **뭐가 가요?** | 숫자뿐이에요 (몇 건 했는지, 검사 통과 수, 주별 처리 시간 중앙값 등) | 티켓 번호, 고객 ID(corpId), 교훈 한 줄, 질문·확인 내용 일부, 함정(pitfall)이면 출처와 관측일, 있는 판례를 놓친 건(`miss`)이면 그 판례 경로 |
| **고객 내용이 있어요?** | **없어요** | **있어요.** 그래서 90일 뒤 지워져요 |
| **언제 가요?** | 세션을 시작할 때 (6시간에 한 번) | 티켓 기록의 `교훈 후보` 칸이 채워졌을 때만 (대부분은 "없음") |
| **미리 보기** | `python3 scripts/report_usage.py` | `python3 scripts/report_lessons.py` |
| **끄기** | 설정 파일에 `TIKET_TELEMETRY=off` (둘 다 꺼져요) | 설정 파일에 `TIKET_LESSONS=off` (이것만 꺼져요) |

설정 파일 위치는 `~/.config/msp/tiket-usage.conf` 예요.

사용 지표를 만들려고 **하루 한 번 내 Zendesk 계정으로** 읽는 것이 있어요 — 내가 해결한 티켓의 처리 시간, 그중 tiket 기록이 있는 수,
내 공개 답변이 AI 초안과 얼마나 같은지. 계산은 내 PC 에서 하고, 나가는 건 **주별 중앙값·합계와 건수**뿐이에요(티켓 번호·본문은 안 가요).
미리 보기는 `python3 scripts/usage_zendesk.py` 예요. 이것만 끄려면 설정 파일에 `TIKET_ZENDESK=off`, 사용 지표 전체는 `TIKET_TELEMETRY=off` 예요.
**기본으로 켜져 있어요.** 끄고 싶으면 위 설정 한 줄을 넣으면 돼요. 이름은 온보딩에서 정하고,
안 정하면 `git user.name` 으로 가요. 보내다 실패해도 일에는 영향이 없어요.

## 배운 게 팀 자산이 되는 길

```
① 티켓을 처리하다 넘어졌어요
   (처음 판단이 틀렸다 · 공식 문서대로 했는데 안 됐다 · 필요한 규칙이 없었다 · "이건 남겨")
        ↓
② AI가 기록 끝 '교훈 후보' 칸에 적어요          ← 대부분 티켓은 "없음"
        ↓
③ 다음 날 자동으로 회사 후보 목록에 모여요
        ↓
④ 관리자가 읽고 승인하거나 반려해요             ← 자동 승인은 없어요
        ↓
⑤ 승인된 건 오답 노트(pitfalls/)나 규칙이 돼요
        ↓
⑥ 새 버전이 나오면 모두의 PC에 자동으로 들어가요
```

같은 실수를 두 번 하지 않게 하는 장치예요.
